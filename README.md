# Truck Haven Digital

Redesign and completely rebuild the website for GS Truck & Trailer Repair using the existing website as the ONLY source of business information:

https://gstruckandtrailerrepair.com/

IMPORTANT: Extract and reuse the exact existing business information from the website, including the same:

Phone number

Address

Email address

Business details

Services

Existing content where relevant

Do not invent new contact information.

MAIN GOAL

Create a premium, modern, cinematic, highly animated truck repair website. The website must NOT feel static or AI-generated.

I want a website with the type of modern motion design currently used by premium automotive, logistics and industrial brands.

Use all the installed/downloaded skills, components and libraries available in this project, especially:

Framer Motion

Advanced UI/UX skills

Max Pro Skin / premium design system

Modern animation components

Premium interaction patterns

Actually USE these libraries and skills in the implementation. Do not create a basic static website.

WEBSITE STRUCTURE

I WANT LESS PAGES.

Ideally create only:

Home

Services

About / Contact

However, the Home page itself should contain most important information so users do not need to navigate through many pages.

The website should feel like a complete premium digital experience rather than multiple separate basic pages.

MOST IMPORTANT: HERO ANIMATION

The hero section needs to be extremely impressive.

Create a cinematic full-screen hero where a large heavy-duty truck dynamically slides/drives into the screen.

Animation concept:

Page loads with a cinematic dark industrial environment.

Headline and UI elements initially appear subtly.

A realistic heavy-duty truck enters the screen from the left or right.

The truck should feel like it is actually driving/sliding into position.

Add realistic motion blur during movement.

Wheels can have subtle rotation or movement.

Add depth using layered background elements.

Add dust/smoke/light effects subtly if appropriate.

Once the truck settles, content animates into place.

Headline, CTA buttons and trust indicators should have staggered animations.

On scroll, the hero should transition smoothly into the next section.

Use Framer Motion for this entire experience.

The animation should feel smooth, premium and cinematic — like a modern automotive website.

DO NOT simply fade in a static truck image.

Use layered motion, parallax, transforms and scroll-triggered animation to create a premium experience.

Hero message should strongly communicate:

24/7 Emergency Roadside Assistance

and prominently display:

+1 (416) 918-2630

Include two strong CTAs:

Call Now
Request Service

MOTION REQUIREMENTS

Motion is one of the most important parts of this project.

Use Framer Motion extensively but intelligently.

Include:

Truck driving/sliding hero animation

Scroll-triggered section reveals

Parallax backgrounds

Text stagger animations

Animated service cards

Hover interactions

Animated buttons

Horizontal scroll experiences where appropriate

Smooth page transitions

Number/stat animations

Subtle background motion

Layered depth effects

Animations must be smooth and premium.

Every animation should have a purpose and contribute to the storytelling.

UX REQUIREMENTS

Premium desktop experience.

Hero animation must also have a good mobile version.

Extremely prominent phone CTA on mobile.

FINAL RESULT

The final website should feel like a premium modern automotive brand website — not a normal local business template.

The visitor should immediately feel:

"These guys are professional, powerful, modern and available 24/7."

Prioritize visual quality, motion design, premium UI/UX and conversion.
